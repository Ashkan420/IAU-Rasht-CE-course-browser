# جستجوی دروس — IAU Course Browser

یک ابزار ساده و سریع برای جستجو، فیلتر و مشاهده دروس دانشگاه آزاد واحد رشت (گروه کامپیوتر).

[**مشاهده سایت ↗**](https://ashkan420.github.io/IAU-Rasht-CE-course-browser/#sem=4051)

---

## امکانات

- 🔍 **جستجو** — بر اساس کد درس، نام درس، نام استاد یا کد ارائه
- 🏷️ **فیلتر دسته‌بندی** — دروس عمومی، تخصصی یا همه
- 👥 **فیلتر جنسیت** — برادران، خواهران یا همه
- ↕️ **مرتب‌سازی** — روی هر ستون کلیک کنید تا مرتب شود
- 🌗 **حالت تاریک/روشن** — با یک کلیک قابل تغییر
- 📥 **دانلود** — خروجی PDF یا XLSX از نتایج فعلی
- 🔗 **لینک قابل اشتراک** — فیلترها و مرتب‌سازی در آدرس ذخیره می‌شوند
- 📅 **نیمسال** — انتخاب نیمسال از منوی کشویی

## نحوه استفاده

1. نیمسال مورد نظر را انتخاب کنید
2. دسته درس (عمومی/تخصصی) را انتخاب کنید
3. در کادر جستجو عبارت مورد نظر را تایپ کنید و Enter بزنید
4. برای اضافه کردن فیلتر بیشتر، روی `+` کلیک کنید
5. روی هر ستون کلیک کنید تا مرتب شود
6. برای دانلود، دکمه PDF یا XLSX را بزنید
